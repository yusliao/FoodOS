# FoodOS 各环节子系统功能模块一览

> 内部资料 · 2026-09-09 · V1.1  
> 供管理层查看：每个环节都是完整子系统；立项仍是一个项目，因为共用一张订单、一个批次。  
> 工程映射与接口见 [概要设计](../FoodOS-概要设计.md)、[详细设计](../FoodOS-详细设计.md)。

能力上每个环节都有完整能力；交付上打成一个 FoodOS，避免六个系统对账。标注 **P0** 为一期必做，**P1/P2** 为后续。

## 总览

| 子系统 | 服务谁 | 一句话职责 | 一期重心 |
|---|---|---|---|
| 1. TOB 订货 Shop | 餐厅/门店采购、销售顾问 | 客户怎么选货、下单、跟单 | 能下单、能改单、能看到履约状态 |
| 2. 交易中枢 | 全系统 | 商品、价格、库存、订单的唯一账本 | 三维库存 + 订单状态机 |
| 3. 供应与质检 | 采购、品控、供应商 | 货怎么进来、合不合格、批次从哪来 | 收货质检与批次事件 |
| 4. 仓储 WMS | 仓管、拣货员 | 货在仓里怎么放、怎么拣、怎么装 | 温区波次 + 效期先出 |
| 5. 运输 TMS | 调度、司机、客服 | 货怎么出门、温控、签收、退货 | 固定线路 + 电子签收 |
| 6. 计划引擎 | 计划员、采购 | 明天备多少、会不会断货呆滞 | 建议+人工确认，不自动写单 |
| 7. 客户经营 | 门店经营者 | 按菜谱/用量把补货做简单 | P2：粘性，不自研收银 |
| 横切：权限/结算/看板 | 运营、财务、管理层 | 谁能做什么、钱怎么对、指标怎么看 | 基础权限与签收对账 |

## 1. TOB 订货 Shop

对标 Sysco SHOP。不是 C 端商城，而是 B 端经营入口：多门店、合约价、截单、复购。

| 功能模块 | 内容概要 | 阶段 |
|---|---|---|
| 组织与账号 | 企业、门店、角色（老板/采购/后厨）；一企多店切换 | P0 |
| 商品目录 | 分类、搜索、筛选、温区标识、缺货/可售展示 | P0 |
| 价格与合同 | 客户价盘、起订金额/件数、协议价，禁止看到别人的价 | P0 |
| 购物车与清单 | 常购清单、收藏、按门店加购、一键复购 | P0 |
| 下单与截单 | 可用量校验、截单日历、截单前改单、超时走加急 | P0 |
| 订单中心 | 订单状态、预计送达、签收结果、历史订单 | P0 |
| 售后协同 | 少货、破损、退货申请，回写同一订单 | P0 基础 / P1 完善 |
| 消息通知 | 截单提醒、缺货、发车、送达 | P0 基础 |
| 销售协同 | 顾问代客下单、客户备注、跟进记录 | P1 |
| 个性化与推荐 | 常购推荐、采购异常提醒、下一品建议 | P2 |
| 开放对接 | 对接客户 ERP / EDI / 开放 API | P2 |

## 2. 交易中枢

Shop、仓库、运输、财务都认这一本账。

| 功能模块 | 内容概要 | 阶段 |
|---|---|---|
| 商品主数据 | SKU、规格、单位换算、温区属性、效期规则、条码 | P0 |
| 价格引擎 | 目录价、合约价、数量阶梯、有效期；下单瞬间锁价 | P0 |
| 库存账 | 仓库 × 温区 × 批次三维记账；预占、在库、待发、在途 | P0 |
| 销售订单 | 状态机：草稿→预占→计划→拣货→在途→签收→对账 | P0 |
| 履约路由 | 自营仓发还是供应商直送；一期可先只走自营仓 | P0 预留 / P2 混履约 |
| 截单引擎 | 按仓/线路配置截单时点，截单瞬间生成日计划 | P0 |
| 采购/调拨单 | 由计划确认后生成，不是预测模型直接写库存 | P1 |
| 编码与主数据治理 | 客户、门店、SKU、批次、订单号规则统一 | P0 |

## 3. 供应与质检

采购下单与合格入库必须分权。

| 功能模块 | 内容概要 | 阶段 |
|---|---|---|
| 供应商主数据 | 资质、品类、交期、结算条款、合作状态 | P0 基础 / P1 门户 |
| 采购执行 | 采购单、催货、到货预约（月台时段） | P0 |
| 配额与集中度 | 单供应商采购占比上限可配置 | P1 |
| 收货质检 | 抽检、合格/不合格、照片凭证；不合格进隔离仓 | P0 |
| 批次管理 | 收货生成或继承 Lot；效期、产地、合格证 | P0 |
| 追溯事件 | 出厂/收货/上架/出库/在途/签收关键节点落库 | P0 |
| 召回工作台 | 输入批次 → 列出库存、在途车次、已送达门店 | P1 |
| 供应商协同门户 | 送货预约、对账、质量反馈 | P1 |
| 供应商评分 | 及时率、合格率、投诉 | P2 |

## 4. 仓储 WMS

生鲜仓关键是温区隔离、效期先出、少拣错。

| 功能模块 | 内容概要 | 阶段 |
|---|---|---|
| 库区库位 | 常温/冷藏/冷冻物理分区；禁止跨温区推荐库位 | P0 |
| 收货上架 | 按质检结果上架；托盘/周转筐扫码与库位绑定 | P0 |
| 库存作业 | 移库、盘点、冻结（临期、温控异常、待检） | P0 |
| 波次计划 | 截单后按温区、线路聚单，生成拣货任务 | P0 |
| 拣货作业 | PDA 扫批次拣货；路径尽量少走 | P0 |
| 效期策略 | 默认 FEFO；临期优先配近途短单 | P0 |
| 复核装托 | 复核件数/称重；托盘与待装车位绑定 | P0 |
| 损耗登记 | 破损、过期、作业损耗记到批次 | P0 |
| 设备扩展 | 电子标签、AGV | 以后 |

## 5. 运输 TMS

| 功能模块 | 内容概要 | 阶段 |
|---|---|---|
| 运力档案 | 车辆、隔舱温区、载重、司机 | P0 |
| 线路与时间窗 | 一期固定线路；门店送达窗口可考核 | P0 |
| 装车发运 | 装车扫码，运单与销售订单绑定 | P0 |
| 司机端 | 导航、拍照/无纸化签收、异常上报、带回退货 | P0 |
| 在途跟踪 | 位置、预计到达；客户订单中心可看 | P0 基础 |
| 温控监测 | 车厢探头；越阈告警并关联受影响订单/批次 | P1 |
| 退货返仓 | 拒收/退货随车返回，回写入库或报损 | P0 |
| 异常判责 | 温控、延误、货损责任环节可追溯 | P1 |
| 路径优化 | 多点时间窗、载重、回程取退货 | P2 |

## 6. 计划引擎

只出建议，计划员确认后才生成采购/调拨。

| 功能模块 | 内容概要 | 阶段 |
|---|---|---|
| 需求预测 | 按 SKU × 门店 × 日 | P1 |
| 补货参数 | 安全库存、补货点、最大库存 | P1 |
| 采购建议 | 结合供应商交期与配额 | P1 |
| 调拨建议 | 多仓仓间补货 | P2 |
| 计划员工作台 | 审核、覆盖、审计日志 | P1 |
| 呆滞与断货预警 | 临期、周转慢、即将断货 | P1 |
| 开业/换季专项 | 新店开业备货、换菜单备货 | P2 |

## 7. 客户经营

一期不自研收银、预订、叫号。

| 功能模块 | 内容概要 | 阶段 |
|---|---|---|
| 菜谱 / BOM | 菜品用料映射到 SKU | P2 |
| 用量建议 | 按历史订单 + 星期节奏 | P2 |
| 一键转购物车 | 建议清单写入 Shop | P2 |
| 经营周报 | 断货次数、浪费、食材成本粗算 | P2 |
| 收银对接 | 对接现有收银/进销存，不自研 POS | 以后 |

## 横切能力

| 功能模块 | 内容概要 | 阶段 |
|---|---|---|
| 组织权限 | 总部/仓/销售/司机/客户角色与数据权限 | P0 |
| 结算对账 | 签收数量、差异、折让、退货回写同一订单 | P0 基础 / P1 完善 |
| 发票与账期 | 账期、授信额度、逾期提示 | P1 |
| 运营看板 | 履约率、缺货率、损耗率、温控达标率 | P0 |
| 消息中心 | 站内信、短信、企微/公众号 | P0 |
| 审计日志 | 改价、改库存、覆盖预测、召回操作 | P0 |
